KATALOG TOKO PLASTIK NUANYAR - cara deploy
1. Netlify: buka app.netlify.com/drop, seret FOLDER ini (berisi index.html dan folder img). Selesai, dapat link https://....netlify.app
2. Vercel: upload folder ini ke GitHub, lalu Import Project di vercel.com (framework: Other). 
Ubah nomor WhatsApp / diskon grosir di bagian "Pengaturan toko" pada index.html (WA_NUMBER, MIN_GROSIR, DISKON_GROSIR).
